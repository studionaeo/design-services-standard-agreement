# 设计服务标准协议书

汇集国内几十家独立工作室的合同样本，参考 AIGA 国际设计服务协议，再对照《民法典》《著作权法》《商标法》《仲裁法》《民事诉讼法》等中国法律，做本土化梳理后形成的一份标准协议文本。

## 使用方式

- **能读取本仓库文件的 AI 工具**（把仓库 clone 到本地，用 DSH、Claude Code、Cursor 等打开）：直接说「把设计服务标准协议书给我」，agent 会读取 `协议/` 文件夹里的文件提供给你；支持 skill 的工具会自动识别内置 skill，效果一致。
- **纯网页版助手**（ChatGPT 等，看不到本仓库）：把 `协议/` 文件夹里对应文件的内容复制粘贴给它，让它原样提供。
